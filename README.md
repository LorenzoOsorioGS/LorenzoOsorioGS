### Projeto em destaque

#### Search+ — Busca de documentos e imagens com IA local

> Sistema de busca por linguagem natural que indexa o conteúdo de arquivos (não o nome) e roda 100% na máquina do usuário, sem nuvem.

Atuo como **Team Lead** e desenvolvedor, em colaboração com Itallo Arruda e João Miguel.

**Minha contribuição técnica:**
- **Front-end:** desenvolvimento da landing page e da interface de busca em **HTML, CSS e JavaScript**, com foco em UX e responsividade.
- **Back-end / integração:** _[descreva aqui o que você fez no servidor — ex.: endpoints em Flask, integração com o modelo de visão, schema do banco. Se não atuou no back-end, troque este item por "Organização técnica e arquitetura da solução".]_
- **Processo:** organização da equipe e do backlog com frameworks ágeis (Scrum, MoSCoW).

**Arquitetura — como funciona:**
```text
[ Upload de Imagem/Documento ]
            ↓
[ IA local gera descrição automática (visão computacional) ]
            ↓
[ Descrição vetorizada e armazenada no banco de dados ]
            ↓
[ Usuário busca por texto em linguagem natural ]
            ↓
[ Sistema cruza a semântica e retorna os arquivos correspondentes ]
```

**Stack do projeto:** Python · Flask · JavaScript · PostgreSQL · Modelos locais de IA (LLaVA + CLIP via Ollama)
