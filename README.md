### 🚀 Projetos em Destaque

🔍 **Search+ — Busca de Documentos e Imagens com IA**
> *Plataforma de busca baseada em inteligência artificial*

O **Search+** é um sistema inteligente de busca por linguagem natural. Atuo como Team Lead do projeto, trabalhando em colaboração com Itallo Arruda e João Miguel. Fui responsável pelo desenvolvimento da Landing Page e pela organização da equipe através de frameworks ágeis.

**Como funciona:**
```text
[ Upload de Imagem/Documento ]
        ↓
[ IA gera descrição automática ]
        ↓
[ Armazena descrição no banco de dados ]
        ↓
[ Usuário busca por texto ]
        ↓
[ Sistema retorna arquivos correspondentes ]
